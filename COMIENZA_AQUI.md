# 🎬 COMIENZA AQUÍ - INSTRUCCIONES SIMPLES

## ¡Tu proyecto está completamente creado! 🎉

Solo necesitas 3 comandos para empezar:

### 1️⃣ Abre Terminal en VS Code
```
Ctrl + ` (backtick)
```
O ve a: `Terminal` > `New Terminal`

---

### 2️⃣ Copia y pega esto en la terminal:
```bash
cd c:\Proyecto_Personal\Hotel && npm install
```

**Espera a que termine** (puede tomar 1-2 minutos la primera vez)

---

### 3️⃣ Después escribe:
```bash
npm run dev
```

✨ **¡Se abrirá automáticamente en tu navegador!** ✨

## ❓ Si algo no funciona

### Error: "npm: command not found"
→ Necesitas instalar Node.js: https://nodejs.org/

### Error: "Puerto 3000 en uso"
→ Abre otro puerto editando `vite.config.ts`

### Otros errores
→ Intenta: `npm install --force` y luego `npm run dev`
